# ALOGOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace INPHIREV with ALOGOS, a four-face all-pass memory whose geometric spiral takes any of four irrational scales (φ, √2, e, π), three densities (1, 2, 4) and five gains, with a memory allocated per setting outside the audio thread; its default setting is INPHIREV, delay for delay.

**Architecture:** Faust is the spec (`sgs.alogos` in `seam.silvi.lib`, `sgs.inphirev` becoming its φ case). The C++ generalises INPHIREV's SDK-free engine: the constants `kPhi`/`kG` become a setting (scale, density, g); the grid index becomes a distance in metres snapped to the grid; the fixed arena becomes a per-setting arena handed over by a worker thread (`alogos_arena.h`). Processor, views, uidesc and state follow INPHIREV's files.

**Tech Stack:** C++17, VST3 SDK + VSTGUI, CMake/ctest, doctest, Faust (`-double`, `sff.np` ffunction) for references only.

**Spec:** `docs/superpowers/specs/2026-10-27-alogos-plugin-design.md` — read it before any task. INPHIREV's code (`plugins/inphirev/`) is the model for every file until Task 9 removes it.

## Global Constraints

- Hand-written C++; `faust -lang cpp` only inside the reference generator, never in `plugins/*/source/`.
- State and arithmetic in `double`; conversion only at the bus.
- Scales r: φ = (1+√5)/2, √2, e, π (menu order). Densities D: 1, 2, 4. ρ = r^(1/D).
- g menu (order): 1/φ, 1/√2, 1/e, 1/π, √(√2−1). Default 1/φ.
- Speed of sound: `Seam::speedOfSound(Seam::kRoomCelsius)` = 343.21462268256795 m/s (`sma.rsos`).
- Delay: `n = floor(fs · d · ρ^(i + k/4) / c + 0.5)`, i.e. `pow(r, (i + k/4.0)/D)`; n < 2 kept, else `PrimeSieve::nextPrimeAbove(n)` (= `sff.np`).
- Grid: `d(id, j) = pow(r, (j + u_id)/(4·D))` metres; u = 0, ½, ¼, ¾, ⅛, ⅝, ⅜, ⅞ for id 1…8, id 0 ("?") u = 0; j ∈ 0…J(r, D), J the largest j with `pow(r, (j + 7/8)/(4D)) ≤ 6` (φ: 14/28/58; √2: 19/40/81; e: 6/13/27; π: 5/11/24).
- The grids do **not** nest across densities; ids stay apart (spec, builder check).
- Distance parameter: metres 1–6, continuous; snapped to the grid point nearest in ratio: `j = clamp(round(4·D·log_r(m) − u), 0, J)`. Default 3.33 m (→ j = 10 at φ, D = 1, id 0/1: 3.3302 m).
- Sections parameter 1–128, default 17; effective N = min(N, N_max), N_max = the largest N ≥ 1 with `d · pow(r, (N − 1 + 3/4)/D) / c ≤ 90.0` s at the snapped distance d.
- Settings applied after 250 ms unchanged; applying runs fade out 25 ms / clear / fade in (if POWER); an identical table (same delays, same N, same g) skips the clear; a change of g alone clears.
- Memory: per setting, each attached section exactly delay + 1 doubles; reallocate when the need exceeds the arena or falls below half of it; never allocate or free in the audio thread; no byte budget (one instance per machine), failure path tested through an injected byte limit.
- Bus 4 in / 4 out, `kAmbi1stOrderACN`, channel k = face k; subcategory `Fx|Reverb`; infinite tail.
- FUID `0x5E4D0015, 0xA1B2C3D4, 0x414C4700, 0x00000015` (word3 "ALG\0"); params 100 Power, 101 StoneId, 102 Distance, 103 Sections, 104 Scale, 105 Density, 106 Gain (= 100 + `alogos::Param` index, which is also the state order).
- Branch `feat/alogos` in both `seam-ltm` and `faust-libraries`; commit per task; no push without asking Giuseppe.
- Configure with `-G Xcode -DSEAM_VST3SDK_DIR=/Users/giuseppe/Documents/github/seam/sdk/vst3sdk`.

## Review Focus

1. **A second settled change while the worker is still allocating**: the end state equals a fresh engine with the last setting, and the arena that lost the race is freed. Test in Task 5.
2. **`setActive(false)` or destruction while the worker holds a pending arena**: no leak, no crash, no use after free. Test in Task 5 (the broker's allocation/free counters balance to zero).
3. **Sample-rate change while loaded** (48 → 96 kHz through release/prepare): delays and arena follow the new rate. Test in Task 5.
4. **Out-of-range or NaN recalled state** (scale 7, density 3, g 9, distance −1 or 40 m, sections 0 or 500): clamped, never indexing outside a table. Test in Task 7.
5. **Sections above N_max survive a round trip of scale**: N = 17 at φ, switch to π (effective 8 at 3.33 m), back to φ → effective 17 again; the stored parameter never changes. Test in Task 4 (engine level) and Task 7 (ParamBox).

### Task 5: Arena broker and engine

**Files:**
- Create: `plugins/alogos/source/alogos_arena.h`, `tests/alogos_engine_test.cpp`
- Modify: `plugins/alogos/source/alogos_dsp.h` (add `Engine`)

**Interfaces — Produces:**
- `class ArenaBroker` (`alogos_arena.h`, namespace `alogos`): `explicit ArenaBroker(std::size_t byteLimit = SIZE_MAX)`; `~ArenaBroker()` (stops and joins the worker, frees everything it holds); `double* allocateNow(std::size_t doubles)` (calling thread, zeroed, nullptr on failure or above the limit); audio thread, lock-free: `void request(std::size_t doubles)` (latest request wins), `double* take(std::size_t& doubles)` (a zeroed arena for the latest request, or nullptr if not ready), `void retire(double*)`, `bool failed() const`; test hooks `long liveArenas() const`.
  The worker waits on its own condition variable with a 2 ms timeout and polls atomics; the audio thread never locks, allocates or frees.
- `class Engine` (`alogos_dsp.h`), INPHIREV's engine with:
  - `bool prepare(double fs, std::size_t byteLimit = SIZE_MAX)`, `void release()`, `void reset()`, `void setPower(bool)`, `void requestReset()`, `template<class T> void process(const T* const*, T* const*, int)`;
  - `void setSettings(int stoneId, double metres, int sections, int scale, int densityIdx, int gain)` — clamps, snaps, computes the effective N; 250 ms settle as INPHIREV;
  - readouts: `delay(k, i)`, `sections()` (effective), `sectionsMax()`, `stoneId()`, `metres()` (snapped), `scale()`, `densityIdx()`, `gain()`, `arenaBytes()`, `sampleRate()`, `status()` with `Status { Unprepared, Ready, Clearing, Allocating, AllocFailed }`, `clears()`.
  - Sequence on a settled change: fade out; if the new table needs more doubles than the arena or fewer than half, `request()` and stay silent in `Allocating` until `take()` returns, then `retire()` the old one (a fresh arena needs no clear); otherwise clear in slices as INPHIREV; reattach sections; fade in.
