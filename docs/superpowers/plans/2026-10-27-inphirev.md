# inphirev Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A four-face golden all-pass memory (VST3, seam-ltm) whose delays follow one golden spiral anchored at the TETRAREC–STONE distance, with a per-STONE-id distance grid that keeps instances from ever sharing a delay.

**Architecture:** Faust is the spec (`seam.silvi.lib`, prefix `sgs`, plus `sma.tsos` in `seam.math.lib`); the C++ is a hand port modelled on stunedrev: an SDK-free engine (`inphirev_dsp.h`) of 4 × 18 `Seam::MoorerAllpass` sections in one `double` arena, a GUI-side decay estimator (`inphirev_decay.h`), a ParamBox, a `SingleComponentEffect` processor, a uidesc with SETUP (StoneId) / OPS / FOOTER.

**Tech Stack:** C++17, VST3 SDK + VSTGUI, CMake/ctest, doctest, Faust (`-double`, `sff.np` ffunction) for references only.

**Spec:** `docs/superpowers/specs/2026-10-27-inphirev-plugin-design.md` — read it before any task.

## Global Constraints

- Hand-written C++; `faust -lang cpp` only inside the reference generator, never in `plugins/*/source/`.
- State and arithmetic in `double`; conversion only at the bus.
- g = 1/φ = `sma.rphi(1)` = (√5−1)/2; φ = `sma.phi(1)`.
- Speed of sound c(T) = 331.3 · √(1 + T/273.15), T = 20 °C (343.21462268256795 m/s); the old `isos`, `esos`, `imt2npsamp`, `kSpeedOfSoundInterior` stay untouched.
- Delay: `n = floor(fs · d · φ^(i + k/4) / c + 0.5)`; n < 2 kept, else the prime strictly above n (`Seam::PrimeSieve::nextPrimeAbove`, = `sff.np`).
- Grid: `d(id, j) = φ^((j + u_id)/4)`, u = 0, ½, ¼, ¾, ⅛, ⅝, ⅜, ⅞ for id 1…8; id 0 ("?") uses u = 0; j ∈ 0…14 (1 m … < 6 m for every id).
- Sections 1–18, default 17; default j = 10 (3.330 m at u = 0); default id 0.
- Settings applied only after 250 ms unchanged; applying runs the RESET sequence (25 ms fade out, sliced clear, fade in if POWER).
- No input/output gain, no FINE zone; window zones per `doc/style/ui-style.md`, started from `plugins/_template/resource/_template.uidesc`.
- Bus: 4 in / 4 out, `kAmbi1stOrderACN`, channel k = face k; subcategory `Fx|Reverb`.
- Work on branch `feat/inphirev` in both `seam-ltm` and `faust-libraries`; commit per task; no push without asking Giuseppe.
- Configure with `-DSEAM_VST3SDK_DIR=../vst3sdk` (subagents miss it otherwise).
- Every test is verified by mutation (break the code, see RED, restore) and the mutation recorded in `doc/study/inphirev/mutations.md`.
- Docs one sentence per line, English.

## Review Focus

1. **Sample-rate change while loaded** (host goes 48 → 96 kHz through `setActive(false/true)`): arena and delay table must follow the new rate. Test in Task 5: `prepare(48000)`, `release()`, `prepare(96000)` → delays equal the 96 kHz reference.
2. **Out-of-range recalled state** (id 9, j 20, sections 0 or 40 from a corrupt or future session): clamp to the ranges, never index outside the table. Test in Task 7.
3. **Allocation failure** (1.13 GiB at 192 kHz on a loaded machine): engine silent, `failed()` true, no exception. Test in Task 5 via a byte limit on `prepare`.
4. **A setting change or a RESET click arriving while a clear is in progress**: the final state equals a fresh engine with the last settings. Test in Task 5.
5. **Hours of silence after a tail**: no subnormals in the arena (the cost must not grow). Test in Task 5: impulse, then 2 M samples of zeros, every output sample is zero or normal (`std::fpclassify != FP_SUBNORMAL`).
